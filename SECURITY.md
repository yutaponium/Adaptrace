# Security Policy

## Supported versions

Only the latest release and the latest commit on `main` receive security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/yutaponium/Adaptrace/security/advisories/new).
You will get a response within 7 days.

脆弱性は公開のIssueに書かず、上のリンクから非公開で報告してください。リンク先はGitHubのPrivate vulnerability reportingです。7日以内に返信します。
